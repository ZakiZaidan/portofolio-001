# Portfolio Clone

Clone website portfolio dengan tema dark mode, dibangun menggunakan React + Vite.

## Tech Stack

- **React 18** - UI Library
- **Vite** - Build tool
- **Framer Motion** - Animasi
- **Lenis** - Smooth scrolling
- **Google Fonts** - Typography (Inter + Playfair Display)

## Fitur

- Dark mode theme
- Smooth scrolling dengan Lenis
- Animasi halus dengan Framer Motion
- Responsive design
- Grid background dengan efek gradient
- Copy email to clipboard
- Back to top button

## Cara Menjalankan

1. Install dependencies:
```bash
npm install
```

2. Jalankan development server:
```bash
npm run dev
```

3. Buka browser di `http://localhost:3000`

## Build untuk Production

```bash
npm run build
```
